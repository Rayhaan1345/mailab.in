A timer is there if you want the pressure of a clock, and about an hour is a fair target.

Question 4Output size, stride and padding

What does this program print? The operator // rounds down. Give a whole number.

def out_size(n, k, s=1, p=0):
    return (n + 2 * p - k) // s + 1

side = 100                      # patch
side = out_size(side, 7, 2, 3)  # conv
side = out_size(side, 3, 2, 1)  # pool
print(side)
