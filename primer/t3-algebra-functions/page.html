This chapter covers the functions you will meet again and again in AI: lines, curves that bend, exponentials, logarithms and the sigmoid, a smooth S-curve. You will learn the rules that simplify them, how to run a function backwards, and how to feed one function into another.

A neural network is a long chain of functions, with the output of one feeding the next. The loss functions of later chapters are built from exponentials and logarithms. SharkCam uses them to turn a shark's length into a weight and a score into a probability.

Functions as machines

Guess first. In the made-up catch table, tags 6894 and 8994 are both spadenose sharks of 49.6 cm. One weighs 0.437 kg and the other 0.297 kg. Could a function turn length into weight for both of them?

function
a rule that gives one output for any input you allow
input, output
the number that goes in (x) and the number that comes out (y or f(x))
domain
the set of inputs the rule accepts
graph
the picture made by all the pairs (x, f(x))

A function is a machine with a single output for any input in its domain, and its graph shows the whole rule at once.

A formula, a unit conversion and a yes-or-no decision are all functions, and moving the input slides one point along the graph.

The answer to the question above is no. A function gives one output for one input, so it can return only one weight for a length of 49.6 cm. Sharks of the same length differ in weight, as these two do, and a function cannot show that spread. The gap is why we later fit a function to data and measure the leftover error (A2).

The first machine uses the length-weight law that generated the made-up spadenose records, \(W = 0.0044\,L^{2.923}\) grams. We write the weight rule as \(W = f(L)\). The letter \(f\) names the machine, and the brackets show what goes in. If you know the rule and the input, the output is fixed. Read the machine left to right in the figure: the coral box is the input, the middle box is the rule, and the navy box is the output.

A function can also make a decision. The third machine returns 1 when the length is at least 35.8 cm and 0 otherwise. At 35.8 cm a female spadenose shark in the made-up table is as likely to be mature as not. Its graph is a step. The classifiers of A3 and B1 are functions of this kind, with a smoother step. The records are made up from published length-weight laws and are not field data.

\[ y = f(x) \]

  • \(x\) is the input, such as a length in cm.
  • \(f\) is the rule that turns the input into an output.
  • \(y\) is the output, such as a weight in kg.

Evaluate the weight machine for Tag 3305, a spadenose shark of 41.0 cm. Raising 41.0 to the power 2.923 gives about 51,781. Multiplying by 0.0044 gives 227.8 grams, and dividing by 1000 gives 0.228 kg, the weight in the table. The rule fixes an output for any length in its domain, and it can mislead outside that domain. A rule fitted to sharks of 18 to 60 cm says little about a shark of 150 cm. Without a check, Python raises a negative length to the power 2.923 and returns a complex number, and NumPy returns nan. Neither is a weight.

def weight_kg(length_cm):
    if length_cm <= 0:
        raise ValueError("length must be positive")
    return 0.0044 * length_cm ** 2.923 / 1000

print(round(weight_kg(41.0), 3))
try:
    weight_kg(-5)
except ValueError as e:
    print("ValueError:", e)
0.228
ValueError: length must be positive

In practice: state the domain of a function in its code, with a check that raises an error. A function that accepts anything returns a wrong number without any warning when the input is wrong.

The vertical line test

Pick a curve and slide the vertical line. Count the points where the line crosses the curve.

Outputs found: 1

A curve is the graph of a function only if no vertical line crosses it twice.

Common belief. Any curve you can draw is the graph of a function.

Why it fails. A circle gives two heights for most inputs. A rule that returns two answers for one input is not a function.

Better account. Use the vertical line test. A curve passes if no vertical line meets it more than once.

Debug tip. A function should return the same output when you give it the same input. If a Python function gives different numbers on repeated calls, it reads a random number or a variable defined outside it. Seed the randomness (0.1) or pass the variable in as an input.

import numpy as np

def weight_kg(length_cm):
    return 0.0044 * length_cm ** 2.923 / 1000    # spadenose law of the made-up table

print(round(weight_kg(41.0), 3))                 # Tag 3305
print(np.round(weight_kg(np.array([20, 30, 41, 50, 60])), 3))
0.228
[0.028 0.091 0.228 0.407 0.693]

Used in: a model is a function from measurements to a prediction (A1); a classifier is a function with yes-or-no outputs (A3).

Quick quiz

Does the circle x² + y² = 4 define y as a function of x?

No. At x = 0 the circle has two points, y = 2 and y = −2, so one input gives two outputs.

What is the domain of the weight machine if spadenose sharks in the table run from 18 to 60 cm?

The lengths from 18 to 60 cm. The formula would accept other numbers, but the sensible domain is where it describes sharks.

The weight rule was fitted on spadenose sharks of 18 to 60 cm. Should you trust its output at 150 cm?

No. The rule was never tested at 150 cm. The formula still returns a number, which makes the mistake easy to miss.

Five families of curves

Guess first. You are about to meet a line, a quadratic (a U), an exponential, a logarithm and a sigmoid. Which one levels off at both ends? Which one has a wall at x = 0 that it can never cross?

family
curves that share one formula and differ only in the numbers inside it
parameter
a number in the formula that you can change (A1)
slope
how much y rises when x rises by 1
asymptote
a line that a curve approaches but never reaches

Five formulas make most of the curves in this primer, and a few sliders move you around inside a family.

Only the sigmoid stays between 0 and 1 whatever its sliders say, and only the logarithm has a wall at x = 0.

Choose a family, move its sliders, then drag the probe to read one output at a time. The boxes under the graph use the same colours as the graph: coral is the input you probe, navy is the output.

Line. The slope \(w\) says how much \(y\) changes when \(x\) grows by 1, and the bias \(b\) is the height at \(x=0\). A neuron's weighted sum is a line (B1).

Quadratic. It has one bend. When \(a>0\) it opens upward and has a lowest point. Squared error turns out to be a quadratic in the weight, which is why gradient descent on a line has one lowest point (A2).

Exponential. It multiplies by the growth factor \(r\) whenever \(x\) grows by 1. Above 1 it explodes. Below 1 it decays towards the x-axis, which is its asymptote.

Logarithm. It undoes the exponential. It only accepts positive inputs, and it grows slowly: doubling the input adds a fixed amount. You will see why in the section on logarithms.

Sigmoid. It squeezes any input into the range 0 to 1, with a smooth step in the middle. The weight \(w\) sets how sharp the step is and the bias \(b\) moves it left or right.

\[ \begin{aligned} \text{line:}\ & y = w\,x + b \\ \text{quadratic:}\ & y = a\,x^2 + b\,x + c \\ \text{exponential:}\ & y = a\,r^{x} \\ \text{logarithm:}\ & y = a\,\log_B x + c \\ \text{sigmoid:}\ & y = \sigma(z) = \frac{1}{1+e^{-z}} \\ & \text{with } z = w\,x + b \end{aligned} \]

  • \(w\), \(b\) are the slope and the bias. In the quadratic, \(a\), \(b\), \(c\) are just three numbers.
  • \(r\) is the growth factor of the exponential, and \(a\) scales the whole curve.
  • \(B\) is the base of the logarithm and \(c\) shifts it up or down.
  • \(e\) is a constant, about 2.718, that appears whenever growth is smooth (you meet it again in the logarithm section).

Compare a line and a curve on the made-up spadenose sharks. The best straight line has slope 0.01545 kg per cm and intercept −0.379 kg. At 41 cm it gives 0.254 kg, against the power law's 0.228. At 60 cm it gives 0.548 against 0.693. At 20 cm it gives −0.070, a negative weight, because the line crosses zero at 0.379 / 0.01545 = 24.5 cm and the table has sharks shorter than that.

Squared error is a quadratic in the weight \(w\). For one shark with length \(x\) and weight \(y\), the error is \((wx - y)^2 = x^2 w^2 - 2xy\,w + y^2\). Now average over the three recurring sharks, with lengths 0.41, 0.44 and 0.82 m, weights 0.228, 0.281 and 2.610 kg, and no intercept. This gives \(a = 0.3447\), \(b = -1.5715\) and \(c = 2.3143\). At \(w = 1\) the loss is 0.3447 − 1.5715 + 2.3143 = 1.0875, the loss printed in 0.1. The lowest point of a quadratic is at \(-b/2a\), here \(w = 2.28\), where the loss is 0.523.

import numpy as np

L = np.array([20, 30, 41, 50, 60])
law = 0.0044 * L ** 2.923 / 1000          # the power law of the made-up table
line = 0.01545 * L - 0.379                # the best straight line
for l, p, q in zip(L, law, line):
    print(l, round(p, 3), round(q, 3))

x = np.array([0.41, 0.44, 0.82])           # lengths in m: Tags 3305, 4127, 5519
y = np.array([0.228, 0.281, 2.610])        # weights in kg
a, b, c = (x ** 2).mean(), -2 * (x * y).mean(), (y ** 2).mean()
print(round(a, 4), round(b, 4), round(c, 4))
print(round(a + b + c, 4))                 # the loss at w = 1
w = -b / (2 * a)
print(round(w, 2), round(a * w ** 2 + b * w + c, 3))

In practice: choose a family from the plot and from what you know of the process, fit it, then look at the leftovers. Extrapolating a line, a quadratic or an exponential beyond the data is the usual mistake.

Common belief. A curve that rises faster and faster is an exponential.

Why it fails. A quadratic also rises faster and faster, and so does the early part of a sigmoid. With only the early part of the data you cannot tell these families apart.

Better account. Look at more of the range, or test the rule. An exponential multiplies by the same factor whenever x grows by 1, while a quadratic adds a growing amount.

Debug tip. When a plot looks empty, check the domain first. A logarithm or a square root of a negative number returns nan in NumPy, and the plot simply skips those points.

Used in: a neuron is a line plus a sigmoid (B1); squared error is a quadratic (A2); softmax and log loss use exponentials and logarithms (A3, 0.7).

Quick quiz

Which family could model a quantity that doubles whenever x grows by 1?

The exponential, with r = 2. The line adds a fixed amount per step, and the quadratic adds a growing amount.

A sigmoid has w = 0. What does its graph look like?

A flat horizontal line at the height \(\sigma(b)\). With no weight the input has no effect.

At what length does the fitted line predict a weight of zero, and what does it predict below that?

At 0.379 / 0.01545 = 24.5 cm. Shorter sharks get a negative weight, which cannot happen, so the line is a poor model at the small end.

Exponents: rules and growth

Guess first. In round 1 one person sends a message to two people. Whoever receives it forwards it to two new people, and so on. In round 10, about how many people receive it: 20, 100 or 1,000?

exponent
how many times the base is multiplied by itself
base
the number being multiplied (we write it B)
exponential growth
growth by a fixed factor per step, like the message
power function
x raised to a fixed exponent, like weight growing as length cubed

An exponent counts repeated multiplication, and a handful of rules let you combine exponents without multiplying anything out.

The answer to the message question is 1,024, because round 10 has \(2^{10}\) receivers. Pick a rule below and move the sliders. The figure computes both sides of the rule and writes the multiplication out when it is short enough to see.

Multiplying powers of the same base adds the exponents, and dividing subtracts them.

The rules follow from counting. \(2^5\) is five twos multiplied, \(2^3\) is three twos, so their product is eight twos: \(2^8\). A negative exponent counts division. \(2^{-3}\) divides by 2 three times, which gives \(1/8\). A fractional exponent undoes a power: \(9^{1/2}\) is the number that gives 9 when squared, which is 3.

\[ \begin{aligned} B^m B^n &= B^{m+n}, & \frac{B^m}{B^n} &= B^{m-n} \\ (B^m)^n &= B^{mn}, & B^0 &= 1 \\ B^{-n} &= \frac{1}{B^n}, & B^{1/n} &= \sqrt[n]{B} \end{aligned} \]

  • \(B\) is the base, any positive number.
  • \(m\), \(n\) are exponents. They can be negative or fractions.
  • \(\sqrt[n]{B}\) is the n-th root: the number that gives \(B\) when multiplied by itself \(n\) times.

The weight rule of the first section uses a power function. If \(W\) grows like \(L^3\), a shark 2 times as long is \(2^3 = 8\) times as heavy. The spadenose law has exponent 2.923, so a shark twice as long is \(2^{2.923} = 7.58\) times as heavy. This near-cube law is behind the log-log fit of A2.

A ratio of weights depends only on a ratio of lengths. If \(W = aL^b\), a shark \(c\) times as long has weight \(a(cL)^b = c^b\,aL^b\), so the weights are in the ratio \(c^b\). The step uses \((cL)^b = c^b L^b\), and it is valid for any exponent. For \(b = 3\) it says that \((cL)(cL)(cL)\) has three factors \(c\) and three factors \(L\). For \(b = 2.923\), a shark 10% longer is \(1.1^{2.923} = 1.32\) times as heavy, and one 50% longer is \(1.5^{2.923} = 3.27\) times as heavy. Tag 4127 grew from 44 to 49 cm in 0.1, and \((49/44)^{2.95} = 1.37\) is the 37% gain in weight.

Exponentials describe fading as well as growth. In the made-up dive log, light falls with depth \(z\) as \(e^{-Kz}\). The mean \(K\) is 0.34 per metre. It is an assumption in the range of turbid coastal water, and no Mumbai measurement was found. With \(K = 0.34\), written as \(r^z\), the factor is \(r = e^{-0.34} = 0.712\) per metre. Light is 18% of the surface value at 5 m, 3.3% at 10 m and 0.11% at 20 m. It halves after 2.04 m of depth.

import numpy as np

Kd = 0.34                       # per metre: an assumed value in the made-up dive log
r = np.exp(-Kd)
print(round(r, 3))
for z in (5, 10, 20):
    print(z, round(r ** z, 4))
print(round(np.log(2) / Kd, 2))  # metres for the light to halve

with np.errstate(over="ignore", under="ignore"):

Power or exponential?

Guess first. The curve \(x^3\) climbs fast. Will it stay above \(2^x\) for ever?

The exponential 2x overtakes any power of x, and it takes longer for higher powers.

Check the race with numbers. At \(x = 8\), \(2^x\) is 256 and \(x^3\) is 512, so the power is ahead. At \(x = 10\) the exponential leads, 1,024 against 1,000. At \(x = 16\), \(2^x = 65{,}536\) equals \(x^4\), and it passes \(x^4\) from there. Doubling \(x\) from 8 to 16 multiplies \(x^3\) by 8 and \(2^x\) by 256.

Common belief. A power such as \(x^3\) and an exponential such as \(2^x\) are the same kind of fast growth.

Why it fails. In \(x^3\) the variable is the base, so the growth slows in relative terms. In \(2^x\) the variable is the exponent, so a step of 1 in x multiplies by 2. The exponential passes \(x^3\) near \(x=10\) and \(x^4\) at \(x=16\).

Better account. Ask whether the variable is in the base or in the exponent. A variable in the base gives a power function. A variable in the exponent gives exponential growth.

Debug tip. In Python the power operator is **. The symbol ^ is XOR (0.4). Also -2**2 is -4 because the power binds tighter than the minus. NumPy integer arrays overflow without any warning: np.array([2])**64 gives [0]. Use floats for big powers.

import numpy as np

print(B**m / B**n, B**(m - n))
print((B**m)**n, B**(m * n))
print(B**-n, 1 / B**n)
print(9**0.5, 27**(1/3))

Logarithms: the exponent finder

Guess first. Start at 1 and keep doubling. How many doublings does it take to pass 1,000?

logarithm
\(\log_B N\) is the exponent \(y\) for which \(B^y = N\)
natural logarithm
the logarithm to base \(e \approx 2.718\), written \(\ln\)
log scale
an axis where equal steps multiply by a fixed factor instead of adding

A logarithm answers the question "which exponent?", and it turns multiplication into addition.

The logarithm rises quickly for small numbers and slowly for large ones: from 100 to 1,000 it adds only about 3.3 doublings.

It takes 10 doublings to pass 1,000, since \(2^{10}=1024\). So \(\log_2 1000\) is a little under 10. The same count appears in 0.2: binary search needs about \(\log_2 n\) steps to find one item among \(n\).

The natural logarithm \(\ln\) uses the base \(e\). Libraries use it by default. In NumPy, np.log is \(\ln\), np.log2 and np.log10 are the other two. Changing the base only scales a logarithm by a constant, so the three curves in the figure have the same form.

Logarithm rules

Pick a rule and move the sliders. The two rows should always agree.

A logarithm of a product is a sum of logarithms, so multiplying numbers becomes adding their logs.

\[ \begin{aligned} \log_B(xy) &= \log_B x + \log_B y \\ \log_B\frac{x}{y} &= \log_B x - \log_B y \\ \log_B(x^k) &= k\,\log_B x \\ \log_B x &= \frac{\ln x}{\ln B} \end{aligned} \]

  • \(x\), \(y\) are positive numbers. A logarithm is undefined for zero and for negative numbers.
  • \(k\) is any exponent.
  • \(B\) is the base. The last rule changes the base using natural logs.

The product rule matters in AI because probabilities of many independent events multiply, and long products of small numbers become too small for a computer to store. Taking logs turns the product into a sum that stays a normal size. This is the idea behind log loss (A3) and cross-entropy (0.7).

Here is the problem with products, in numbers. Suppose a detector gives the correct species a probability of 0.3 in 1,000 frames. The product is about \(10^{-523}\), far below the smallest number a 64-bit float can store, so the computer returns 0.0. The sum of logs is \(1000 \times \ln 0.3 = -1204\), an ordinary number that still compares correctly with other runs.

Logs also turn ratios into differences. A small percentage change moves the log by about the same amount. Here \(\ln 1.05 = 0.049\) and \(\ln 1.10 = 0.095\), while a drop of 10% is \(\ln 0.9 = -0.105\). To undo an exponent, take a log of both sides. When does light fall to 1% of the surface value, with light \(= e^{-0.34z}\)? Set \(e^{-0.34z} = 0.01\), so \(-0.34z = \ln 0.01 = -4.605\) and \(z = 13.5\) m. Counting bits is a log too: 600 records need \(\lceil\log_2 600\rceil = 10\) bits, since \(2^9 = 512 < 600 \le 1024\).

import numpy as np

p = np.full(1000, 0.3)                       # probability of the right species in 1,000 frames
print(np.prod(p), np.sum(np.log(p)).round(1))
print(np.log(1.05).round(3), np.log(1.10).round(3), np.log(0.9).round(3))
print((np.log(0.01) / -0.34).round(1))      # depth for 1% light
print(np.ceil(np.log2(600)))

Straight lines from curves

Guess first. Weight depends on length raised to a power near 3. If you plot the logarithm of weight against the logarithm of length, what kind of curve do you expect?

Made-up catch records generated from published length-weight relationships; not field data.

On log axes the cube law becomes a straight line, and its slope is the exponent.

If \(W = a L^b\), then \(\ln W = \ln a + b \ln L\). That is a line with slope \(b\) and intercept \(\ln a\). Fitting a line to the logs gives the exponent: 2.92 for the 268 spadenose records, 3.06 for the 200 milk shark records, 2.95 for the 72 bamboo shark records. The same trick reads exponents off any chart with log axes (0.8).

The scatter of the records also looks different on log axes. Tags 6894 and 8994 are spadenose sharks of 49.6 cm that weigh 0.437 and 0.297 kg, a ratio of 1.47 and a log difference of \(\ln(0.437/0.297) = 0.386\). The made-up weights scatter by about 14% around the law at all lengths. On raw axes that scatter grows with the size of the shark. On log axes it has the same height at all lengths, which is why the straight-line fit is done on logs.

Common belief. Taking logs changes the data, so a fit on the logs is a different problem.

Why it fails. The log relabels the axes, and the same records are still there. A power law stays a power law, and only the picture straightens. The fit does measure its errors as ratios instead of kilograms, which suits data that spans a wide range.

Better account. Logs change the scale you read, which is why they help with data that spans a wide range.

Debug tip. np.log(0) is -inf and np.log(-1) is nan, and both spread into all numbers computed from them. Check that all inputs are positive before taking a log, or add a tiny constant such as 1e-12.

import numpy as np

print(np.log2(1000), np.log(1000), np.log10(1000))
x, y = 8.0, 32.0
print(np.log2(x * y), np.log2(x) + np.log2(y))
print(np.log2(x ** 3), 3 * np.log2(x))

In practice: add a tiny constant such as 1e-12, or clip probabilities, before taking a log. np.log1p(x) computes \(\ln(1+x)\) accurately when \(x\) is tiny. Training losses use natural logs, so a loss of 0.69 is \(\ln 2\), the score of a coin flip between two classes.

Used in: the cube-law fit (A2); log loss (A3); log probabilities and perplexity (0.7, D3); Big-O (0.2).

Quick quiz

Compute \(\log_2 8 + \log_2 32\) without a calculator.

It is 3 + 5 = 8. By the product rule this is also \(\log_2 256\), and \(2^8 = 256\).

Why does a log-log plot of a cube law have slope 3?

Because \(\ln W = \ln a + 3 \ln L\), a straight line in \(\ln L\) whose slope is the exponent.

A detector gives the right class a probability of 0.5 in 20 independent frames. What is the natural log of the product?

\(20 \ln 0.5 = -13.86\). The product itself is \(2^{-20} \approx 9.5 \times 10^{-7}\), and the log is easier to handle.

Inverse functions

Guess first. The machine x² sends both 2 and −2 to 4. If the machine gives out 4, which input went in?

inverse function
the function \(f^{-1}\) that undoes \(f\), so that \(f^{-1}(f(x)) = x\)
one-to-one
different inputs always give different outputs
reflection
the mirror image of a graph across the line y = x

An inverse runs a machine backwards, and its graph is the mirror image of the original across the line y = x.

Swapping the roles of x and y mirrors the graph across the diagonal, and only a one-to-one function has a mirror that is also a function.

To find an inverse by algebra, write \(y=f(x)\) and solve for \(x\). For the temperature rule \(F = 1.8C + 32\) this gives \(C = (F-32)/1.8\). The exponential and the natural logarithm are inverses of one another, so \(\ln(e^x) = x\) and \(e^{\ln x} = x\). That is how a logarithm "undoes" an exponent.

Choose \(x^2\) with all inputs and watch the mirror: it bends back on itself, and one input would need two outputs. Restricting the domain to \(x \ge 0\) repairs it, and the inverse is the square root.

\[ \begin{aligned} f^{-1}\big(f(x)\big) &= x \\ f\big(f^{-1}(y)\big) &= y \end{aligned} \]

  • \(f^{-1}\) is the inverse of \(f\). The small \(-1\) is a name, not an exponent.
  • \(y\) is a value in the output of \(f\), so the second equation starts from an output.

The inverse of the weight law estimates a length from a weight. Start with \(W = 0.0044\,L^{2.923}\) in grams. Divide by 0.0044: \(L^{2.923} = W/0.0044\). Raise both sides to the power \(1/2.923 = 0.3421\), which undoes the power by the rule \((B^m)^n = B^{mn}\): \(L = (W/0.0044)^{0.3421}\). For 228 g, \(W/0.0044 = 51{,}818\) and \(51{,}818^{0.3421} = 41.0\) cm, the length of Tag 3305.

The inverse is a guess when the data scatter. Tags 6894 and 8994 are both 49.6 cm, and their weights of 437 and 297 g send the inverse back to 51.2 and 44.9 cm. The law gives the typical weight at a length, and individual sharks scatter around it. Fitting length on weight directly gives a slightly different curve from inverting the weight law. A function that is flat over a stretch has no inverse either. ReLU (B1) sends all negative inputs to 0, so its output cannot say which one went in.

import numpy as np

a, b = 0.0044, 2.923
def length_cm(W):                              # the inverse of W = a * L**b
    return (W / a) ** (1 / b)

print(round(length_cm(228.0), 1))
print(round(length_cm(437.0), 1), round(length_cm(297.0), 1))   # Tags 6894 and 8994, 49.6 cm

p = np.array([0.1, 0.5, 0.9])
z = np.log(p / (1 - p))                        # the logit: it undoes the sigmoid
print(z.round(3), (1 / (1 + np.exp(-z))).round(3))

Common belief. Any function can be run backwards.

Why it fails. If two inputs give the same output, the output does not say which input it came from. The machine \(x^2\) sends both 2 and −2 to 4.

Better account. A function has an inverse when different inputs give different outputs. Restricting the domain, such as \(x \ge 0\) for \(x^2\), repairs a function that fails this test.

Debug tip. \(f^{-1}(x)\) means the inverse function. It does not mean \(1/f(x)\). The inverse of \(2x\) is \(x/2\), while \(1/(2x)\) is a different function. In code, round-trip a few values: f_inv(f(x)) should give back x.

import numpy as np

x = np.array([-1.0, 0.0, 2.0])
y = np.exp(x)
print(np.log(y))          # undoes the exponential

c = np.array([26.0, 28.0, 30.0])   # sea temperature, deg C
f = 1.8 * c + 32
print(f)
print((f - 32) / 1.8)     # back to Celsius
[-1.  0.  2.]
[78.8 82.4 86. ]
[26. 28. 30.]

Quick quiz

What is the inverse of \(f(x) = 3x - 6\)?

Solve \(y = 3x - 6\) for \(x\): \(x = (y+6)/3\). So \(f^{-1}(y) = (y+6)/3\).

Why has \(x^2\) no inverse on all inputs?

Two different inputs, such as 2 and −2, give the same output, so the output cannot tell you which input went in.

Two sharks of 49.6 cm weigh 437 g and 297 g. Why does the inverse of the weight law return different lengths for them?

The law gives a typical weight for a length. The two sharks scatter above and below it, and inverting one weight passes that scatter into the length.

Composition: functions inside functions

Guess first. Take the line \(f(x)=2x+1\) and the squaring function \(g(u)=u^2\). Does "line, then square" give the same curve as "square, then line"?

composition
feeding the output of \(f\) into \(g\); the result is written \(g(f(x))\) or \((g\circ f)(x)\)
stage
one function in a chain
collapse
when a chain of stages is the same as a single stage

Feeding one function into another builds a new function, and the order of the two matters.

Swapping the order gives a different curve, and two lines in a row collapse into one line.

The figure starts with a line feeding a sigmoid, which is a neuron: \(\sigma(wx+b)\) (B1). Try other pairs. Press "swap f and g" and watch the teal curve change. Now check the guess. At \(x=3\), "line, then square" gives \((2\cdot 3+1)^2 = 49\). "Square, then line" gives \(2\cdot 3^2+1 = 19\).

A neural network is a chain of stages, and the stages are simple functions. A deep network composes dozens. When you ask how much the final output moves if the input moves a little, the answer is a product of the slopes of the stages. That is the chain rule (0.6).

\[ \begin{aligned} (g\circ f)(x) &= g\big(f(x)\big) \\ &= w_2(w_1 x + b_1) + b_2 \\ &= (w_2 w_1)\,x + (w_2 b_1 + b_2) \end{aligned} \]

  • \(g\circ f\) reads "g after f": apply \(f\) first, then \(g\).
  • \(w_1, b_1\) belong to the first line, and \(w_2, b_2\) to the second.
  • The right-hand side is one line with slope \(w_2 w_1\) and bias \(w_2 b_1 + b_2\).

Trace the neuron of the figure at \(x = 2\) with \(w = 1.5\) and \(b = -1\). The line stage gives \(z = 1.5 \times 2 - 1 = 2.0\). The sigmoid stage gives \(1/(1 + e^{-2}) = 0.881\). Add a third stage, a line with weight 2 and bias 0.5, and the output is \(2 \times 0.881 + 0.5 = 2.262\). The sigmoid in the middle is the bend. Without it the two lines would collapse into one.

Slopes multiply along a chain. With \(f(x) = 2x + 1\) and \(g(u) = u^2\), the slope of \(f\) is 2 and the slope of \(g\) at \(u = 7\) is \(2u = 14\). The slope of \(g(f(x))\) at \(x = 3\) is therefore \(2 \times 14 = 28\). A check: moving \(x\) from 3 to 3.01 moves the output from 49 to 49.2804, a change of 0.2804 over 0.01, which is 28.04.

import numpy as np

f = lambda x: 2 * x + 1
g = lambda u: u ** 2
h = 0.01
print(round(g(f(3 + h)) - g(f(3)), 4), round((g(f(3 + h)) - g(f(3))) / h, 2))

x = 2.0
z = 1.5 * x - 1                       # line
s = 1 / (1 + np.exp(-z))              # sigmoid
print(z, round(s, 3), round(2 * s + 0.5, 3))   # a third stage: a line
0.2804 28.04
2.0 0.881 2.262

In practice: a pipeline is a composition: standardise, predict, then turn a probability into a label. The order matters, as \(g(f(x)) \ne f(g(x))\) in general. nn.Sequential in PyTorch composes layers in the order you list them (B1).

Common belief. Stacking more lines gives a more flexible model.

Why it fails. Two lines in a row collapse into one line, as the equation shows. Ten lines in a row also collapse into one.

Better account. Put a bend between the lines, such as a sigmoid. Then the chain can make curves a single line cannot. B2 builds on this.

Debug tip. If a composed function gives nan, check the output of the first stage against the domain of the second. A negative output fed into a logarithm is the usual cause.

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def line(x, w, b):
    return w * x + b

x = np.array([-2.0, 0.0, 2.0])
print(sigmoid(line(x, 1.5, -1.0)))   # a neuron

w1, b1, w2, b2 = 2.0, 1.0, -0.5, 3.0
print(w2 * (w1 * 4 + b1) + b2)         # line, then line
print((w2 * w1) * 4 + (w2 * b1 + b2))  # one line

Quick quiz

With \(f(x)=x+1\) and \(g(u)=u^2\), what is \(g(f(3))\) and what is \(f(g(3))\)?

\(g(f(3)) = 4^2 = 16\) and \(f(g(3)) = 9 + 1 = 10\). The order matters.

Two lines have slopes 3 and −2 and are fed into one another. What is the slope of the composite?

The slopes multiply: \(3 \times (-2) = -6\).

With \(f(x) = 3x\) and \(g(u) = u^2\), what is the slope of \(g(f(x))\) at \(x = 2\)?

At \(x = 2\), \(f = 6\) and the slope of \(g\) is \(2 \times 6 = 12\). Multiply by the slope of \(f\), 3, to get 36. Check: \(g(f(x)) = 9x^2\) has slope \(18x = 36\).
