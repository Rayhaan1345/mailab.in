How to use this set

  • Close the chapters. Keep a pen, paper and a calculator beside you.
  • Choose a time and press Start timer when you begin. Pause it when you leave. The clock counts down, then goes on counting past zero so that you can see how long you took. The timer is optional.
  • Skip a question and return to it if you like. Your answers are saved in this browser as you type.
  • Press Score my answers at the end. The set is scored only then.
Time allowed

Your answers and the timer are saved in this browser only. No data is sent anywhere.
